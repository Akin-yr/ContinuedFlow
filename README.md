# ContinuedFlow | NASA Space Apps Challenge 2024
**A Data-Driven Weather Intelligence Engine for High-Resolution Hazard Monitoring.**

---

## 🏆 Achievement
* **Top 10 Finalist (Local Lead)** - NASA Space Apps Challenge 2024.

## ⚙️ Core Technical Contribution (My Primary Role)
While the project was a team effort, I served as the **Core Logic & Data Engineer**, architecting the system's "brain" (`script.js`) to handle complex environmental telemetry.

### Key Implementations:
* **Asynchronous Data Orchestration:** Engineered the core logic to synchronize real-time streams from **NASA POWER API** (climatological parameters) and **Open-Meteo API** (short-term forecasting).
* **Mathematical Normalization:** Developed a specialized module to standardize heterogeneous data units and align disparate spatiotemporal structures from satellite sources.
* **Robust Error Handling:** Implemented fail-safe asynchronous fetch mechanisms to ensure system reliability during high-pressure disaster response simulations.
* **Data-to-UI Pipeline:** Designed the back-end data structure that feeds processed analytics into dynamic visualization layers.

## 🛠 Tech Stack
* **Logic:** JavaScript (ES6+ Asynchronous Programming).
* **Data Ingestion:** NASA Earth Observation (EO) Data, Open-Meteo Forecasting API.
* **Methods:** Time-series data normalization and spatiotemporal analysis.

## 📍 Research Context
This logic provides the foundational framework for my ongoing **Independent Research** on **Sinkhole Early Warning Systems**, where I am integrating **Deep Learning (LSTM/GRU)** to extend prediction horizons to a 3-month sub-seasonal scale.
